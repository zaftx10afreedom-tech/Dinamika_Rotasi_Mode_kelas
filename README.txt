DINAMIKA ROTASI | MODE PRESENTASI KELAS PID
=========================================

PAKET YANG DISEDERHANAKAN
- Hanya Mode Presentasi Kelas; langsung terbuka ketika aplikasi dijalankan.
- 11 slide dari 11_Bab 4.pptx, ditampilkan sebagai gambar WebP 1920 x 1080.
- Tidak ada laboratorium virtual dan tidak ada menu simulasi.
- Tidak menambahkan kuis, karena versi Dinamika Rotasi sebelumnya belum berisi kuis.
- Berfungsi tanpa PowerPoint desktop maupun layanan daring tambahan.

PENGGUNAAN
1. Ekstrak ZIP ke folder pada komputer/server.
2. Jalankan index.html melalui Chrome/Edge untuk percobaan lokal.
3. Untuk penggunaan di sekolah, unggah seluruh isi folder ke hosting statis.
4. Ketuk tombol layar penuh, lalu geser satu jari ke kiri atau kanan.
5. Ketuk Pena untuk menulis di atas slide; sentuh lagi untuk kembali navigasi.
6. Gunakan Daftar Slide untuk memilih materi, dan Alat untuk membuka kontrol kembali.

FITUR
- Geser satu jari untuk slide berikut/sebelumnya.
- Cubit dua jari untuk pembesaran, tarik untuk menggeser ketika diperbesar.
- Pena digital, laser, urungkan/hapus anotasi per slide.
- Anotasi dan slide terakhir tersimpan lokal di browser (localStorage).
- Bilah alat bersembunyi otomatis dalam 8,5 detik (kecuali pena aktif).
- Mode layar penuh, tombol sisi, daftar slide, dan pintasan papan ketik.
- Seluruh proses di perangkat pengguna; paket bisa dibagikan melalui CDN.

KETERBATASAN
- Slide dirender sebagai gambar. Teks, diagram dan rumus tidak dapat diedit per objek.
- Animasi atau efek PowerPoint tidak ditransformasikan menjadi animasi HTML5.
- Browser dan perangkat PID tertentu perlu diuji langsung untuk kestabilan gestur.
- Tidak ada kuis atau sistem nilai pada versi ini.
- Tidak ada pelacakan akun terpusat.

CATATAN EDITORIAL
Pada salah satu slide sumber, heading menyebut Hukum III Newton, tetapi persamaan
resultan torsi Στ = Iα merupakan penerapan Hukum II Newton untuk rotasi.
Konten slide sumber dipertahankan tanpa diubah.
